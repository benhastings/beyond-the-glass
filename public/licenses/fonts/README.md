# Font licences

The web fonts in this site are subsets of these typefaces, each under the SIL Open Font License 1.1:

| Typeface | Licence | Upstream |
|---|---|---|
| Bricolage Grotesque | [bricolagegrotesque-OFL.txt](bricolagegrotesque-OFL.txt) | https://github.com/ateliertriay/bricolage |
| Atkinson Hyperlegible Next | [atkinsonhyperlegiblenext-OFL.txt](atkinsonhyperlegiblenext-OFL.txt) | https://github.com/googlefonts/atkinson-hyperlegible-next |
| Atkinson Hyperlegible Mono | [atkinsonhyperlegiblemono-OFL.txt](atkinsonhyperlegiblemono-OFL.txt) | https://github.com/googlefonts/atkinson-hyperlegible-next-mono |

The subsets are built by `scripts/fonts/build-fonts.py` from the files in https://github.com/google/fonts.
