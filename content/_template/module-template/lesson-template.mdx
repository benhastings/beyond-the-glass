Each <Term id="pod">pod</Term> runs one or more containers. The cluster decides which machine runs it.

<Depth>
  <ELI5>
    A pod is a box the cluster puts your program in. The cluster can start it, stop it and move it.
  </ELI5>
  <Operator>
    A pod is what the scheduler places on a node: one or more containers sharing an IP address and
    volumes.
  </Operator>
  <DeepDive>
    The kubelet asks the container runtime for a pod sandbox, then starts each container inside it.
  </DeepDive>
</Depth>

</Step>
