# E0-04 evidence

## E0-04.AC1
**Before merge (verified):** GitHub reads issue forms from `.github/ISSUE_TEMPLATE/*.yml` and the PR
template from `.github/pull_request_template.md`, both on the default branch only. `tests/repo/templates.test.ts`
parses all four forms (bug, feature, lesson, scenario) and checks each has a name, a description, and an id
and label on every field, which are the keys GitHub rejects a form without. `config.yml` turns off blank issues.

**After merge (pending, to be confirmed against `main`):**

- Issue forms: the GitHub API doesn't list YAML forms (checked against vitejs/vite, whose YAML forms return
  `issueTemplates: []`), and the chooser page needs a login. Confirm by opening
  https://github.com/benhastings/beyond-the-glass/issues/new/choose and seeing Bug, Content / lesson, Feature and Scenario.
