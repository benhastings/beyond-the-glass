# Evidence for manual acceptance criteria

One file per plan issue (`E6-09.md`) or epic (`E6.md`). Each manual criterion gets a heading with its tag, followed by the evidence: what was checked, how, by whom, and links to recordings or screenshots attached to the PR.

```markdown
## E6-09.AC1
<what was verified, environment/AT versions, outcome, link>
```

See [`docs/testing/acceptance-criteria.md`](../testing/acceptance-criteria.md). Changes here require CODEOWNER review.
