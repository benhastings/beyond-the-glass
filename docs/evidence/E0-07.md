# E0-07 evidence

## E0-07.AC2
ADR-005 records the decision (visx) and the measured gzip size of the same sample time-series panel in each
candidate: Recharts 3.11.1 adds 110.5 KB gzipped over a React-only baseline, and visx 4.0.0 adds 24.7 KB.
Render time for 6 hours of data (2 × 1,440 points) was also measured: Recharts 169.0 ms (over the 100 ms
budget in AGENTS.md §5) and visx 36.4 ms, as the median of 9 loads in headless Chromium.

Measured on 2026-11-23 on the author's machine (Linux, Node 26.8.1, Vite 8). The spike's source and lockfile
are in `docs/adr/spikes/005-charting/`; `npm ci && npx playwright install chromium && npm run measure` reruns
it and prints the same table. Sizes are deterministic for the locked versions; render times vary with the
machine, but the ratio between the two libraries is what the decision rests on.
